## Project 3: SQL Data Analysis

**Goal:** Use SQL to extract insights from an e-commerce orders dataset (1,200 orders).

**File:** `project3_sql_analysis.sql`

**Skills demonstrated:**
- `SELECT` with column selection
- `WHERE` filtering
- `ORDER BY` sorting
- `GROUP BY` aggregation
- `COUNT`, `SUM`, `AVG` functions
- `HAVING` to filter aggregated results
- Subqueries for percentage-of-total calculations

**What the queries answer:**
1. Which orders have been delivered?
2. Delivered orders sorted from highest to lowest value
3. How many orders exist per product?
4. Total revenue and average order value per product
5. Which products generate more than ₦180,000 in revenue?
6. Each product's revenue as a percentage of total company revenue

**Key finding:** Printer and Chair are nearly tied as the top revenue-generating products, each contributing ~15.5% of total revenue, while Phone contributes the least at 12%.
